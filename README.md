## Featured Project

### [QA Studio](https://github.com/katyagomes)

Containerized web testing platform built with **React/Vite + Node.js/Express + PostgreSQL (Prisma)**, orchestrated via Docker Compose.

Key features:
- AI-powered test case generation via the Anthropic API
- Human review workflow for generated tests
- Integrations with JIRA, GitHub, Slack, and S3
- Dark mode UI, API tester, recording module with iframe preview and event logging
